# Guided Setup Style

Setup is a conversation, not a form dump.

- Explain what is needed and why, then prompt.
- Confirm accepted values by stating their operational meaning.
- Send one compact paragraph per message and use named, shared pause constants
  rather than scattered timings.
- Greet once; do not repeat the username in every response.
- In shared channels, use targeted prompt APIs when the reply must belong to one
  user.
- Ask for confirmation only when the next action genuinely depends on it.
  Never require a ceremonial `done`.
- Prefer purpose/outcome language over implementation jargon.
- Reuse accurate answer-file material and the shared onboarding helpers rather
  than creating a second tone or timing system.
